  治具及模具管理系統（Jig & Toolings Management System）
  macOS 網路版安裝說明  v1.4.0
  ※ 請先讀完本說明再開始安裝，可避免大部分的安裝錯誤
  English version: INSTALL-GUIDE-macOS-en.txt
================================================================

【下載區】
https://github.com/gossipred/jig-toolings-network-distribution/releases/latest

需要下載的檔案：
  1. XAMPP-installer.dmg（MySQL 資料庫）
  2. jig-toolings-network-macos-1.4.0.zip（治具系統）

XAMPP 也可以到官方網站下載：https://www.apachefriends.org/download.html
（建議用下載區的 XAMPP-installer.dmg，是我們測試過的版本）

安裝在「伺服器電腦」上（一台就好）。同公司其他電腦（Mac 或 Windows 都可以）
不用安裝，用瀏覽器連過來即可使用。

【安全性提示：「無法確認開發者」怎麼辦】
macOS 開啟下載的檔案時可能跳出「無法打開，因為無法確認開發者」：
  1. 先按「完成」或「取消」關掉提示
  2. 打開「系統設定」→「隱私權與安全性」，往下捲
  3. 看到「已阻擋 XXX」旁邊的「強制打開」→ 點它，輸入密碼
  4. 再點兩下原本的檔案，選「打開」
  （舊版 macOS 也可以在檔案上按右鍵 →「打開」）

================================================================
第 1 步：安裝 XAMPP（MySQL 資料庫，只需裝一次）
================================================================
1. 點兩下「XAMPP-installer.dmg」，再點兩下裡面的安裝程式
   （遇到「無法確認開發者」請照上方【安全性提示】處理）
2. M 系列晶片（Apple Silicon）的 Mac 若詢問是否安裝 Rosetta → 選「安裝」
   （XAMPP 是 Intel 版程式，需要 Rosetta 才能執行）
3. 一直按「Next」，保持預設選項，安裝位置保持「/Applications/XAMPP」
4. 安裝完成後最後一頁的「Launch XAMPP」可以取消勾選
   （MySQL 會在第 3 步自動設定，不需要打開 XAMPP 的控制面板）

================================================================
第 2 步：解壓縮治具系統
================================================================
1. 點兩下「jig-toolings-network-macos-1.4.0.zip」解壓縮
2. 把解壓出來的「mac-network-app」資料夾搬到固定位置
   （例如「應用程式」或自己的使用者資料夾，不要放在「下載」後就刪掉）
3. 【一次解除所有腳本的安全性封鎖（建議）】
   打開「終端機」，輸入以下指令（mac-network-app 可直接拖進終端機產生路徑），按 Enter：
     xattr -dr com.apple.quarantine （拖入 mac-network-app 資料夾）
   這樣之後點兩下 .command 檔就不會一個一個被擋

================================================================
第 3 步：設定 MySQL 開機自動啟動（只需做一次）
================================================================
1. 打開 mac-network-app → scripts，點兩下「setup-mysql-autostart.command」
2. 終端機視窗會要求輸入 Mac 登入密碼（輸入時畫面不顯示字元，打完按 Enter）
3. 看到「[OK] MySQL is running and will start automatically at every boot.」
   就完成了。以後開機 MySQL 會自動啟動，不需要打開 XAMPP 控制面板
   （新版 macOS 可能擋掉 XAMPP 控制面板，所以改用這個方式）

   若出現 [ERROR]，請截圖給我們。
   要取消自動啟動：點兩下 scripts 裡的「remove-mysql-autostart.command」

================================================================
第 4 步：建立資料庫（只需做一次）
================================================================
1. 在 scripts 資料夾點兩下「install-database.command」
2. 問密碼時直接按 Enter（XAMPP 預設沒有密碼）
3. 看到「Database installation completed!」就完成了

================================================================
第 5 步：啟動與登入
================================================================
1. 點兩下 mac-network-app 裡的「START-JIG-NETWORK-APP.command」
2. 終端機視窗會自動檢查 Java、MySQL、8080 port
3. 看到「[OK] The system is ready.」後，瀏覽器會自動開啟登入頁
4. 預設帳號 admin ／ 密碼 123456
   ⚠️ 登入後請立刻到「帳號設定」修改密碼！

   如果看到 [ERROR]：
   - MySQL is not responding → 再執行一次 scripts/setup-mysql-autostart.command
   - Port 8080 is already in use → 先執行 scripts/stop-system.command 再重新啟動
     仍然被佔用（其他軟體在用 8080）→ 執行 scripts/change-port.command 換一個 port，
     詳見 PORT-CHANGE-GUIDE-macOS.txt

================================================================
第 6 步：試用與正式授權
================================================================
• 第一次啟動自動開始 30 天免費試用，不需要授權檔
  剩餘天數可在系統的「授權（License）」頁面查看
• 購買正式授權：
  1. 在「授權」頁面複製 Machine ID
  2. 到 https://aurastudio.studio/license-center/ 登記
  3. 確認收款後，授權檔（.lic）會寄到您的信箱
  4. 在「授權」頁面選擇 .lic 檔 → Install License
• 授權綁定「伺服器電腦」，其他電腦用瀏覽器連線不需要另外授權

================================================================
【同公司其他電腦使用】
================================================================
1. 在伺服器執行 scripts/show-network-address.command，查詢區域網路 IP
2. 其他電腦用瀏覽器開啟 http://（那個 IP）:8080
3. 連不上時，在伺服器執行 scripts/open-firewall.command

【資料備份與還原】
================================================================
系統每天自動備份資料庫與上傳的附件（照片、圖檔）（預設 18:00，可在「系統設定 → 資料備份」修改）。
停止系統時若今天還沒備份，會先備份再停止；
備份時間電腦沒開，下次開機後自動補做。
• 備份位置：backups/auto/（預設保留最近 10 份）
• 附件備份：放在 backups/auto/uploads-mirror，只複製新增或修改過的檔案
• 外接裝置：可在系統設定指定外接硬碟或 NAS，每次備份會把資料庫與附件一起存一份
• 手動備份：系統設定的「立即備份」，或點兩下 scripts/backup-now.command
• 還原資料：詳見 RESTORE-GUIDE-macOS.txt（系統設定的「還原說明」按鈕也能開啟）

【版本更新】
================================================================
v1.3.1 起支援線上更新：有新版本時，在伺服器點兩下
  scripts/UPDATE-JIG-NETWORK-APP.command
即可自動備份、下載、更新並重新啟動，設定、授權、附件與資料全部保留。
詳細步驟與注意事項見 UPDATE-GUIDE-macOS.txt。
（v1.3.0 以前的版本需先依該說明手動升級一次）
