================================================================
  治具及模具管理系統（Jig & Toolings Management System）
  Windows 網路版安裝說明  v1.3.1
  ※ 請先讀完本說明再開始安裝，可避免大部分的安裝錯誤
  English version: INSTALL-GUIDE-Windows-en.txt
================================================================

【下載區】
https://github.com/gossipred/jig-toolings-network-distribution/releases/latest

需要下載的檔案（兩種安裝方式擇一）：
  方式 A（建議）：XAMPP-installer.exe ＋ JigToolingsSetup-1.3.1.exe
  方式 B（手動）：XAMPP-installer.exe ＋ jig-toolings-network-windows-1.3.1.zip

XAMPP 也可以到官方網站下載：https://www.apachefriends.org/download.html
（建議用下載區的 XAMPP-installer.exe，是我們測試過的版本）

安裝在「伺服器電腦」上（一台就好）。同公司其他電腦不用安裝，
用瀏覽器連過來即可使用。

================================================================
第 1 步：安裝 XAMPP（MySQL 資料庫，兩種方式都要做，只需一次）
================================================================
1. 點兩下「XAMPP-installer.exe」
2. 跳出「UAC / Program Files」英文警告視窗 → 按「確定」即可
   （這是 XAMPP 固定的提醒，不需要關閉 UAC）
3. 「Select Components」頁：只需要 MySQL。
   Tomcat、Perl、FileZilla、Mercury、Webalizer、Fake Sendmail
   都可以取消勾選，安裝會快很多
   （Apache、PHP 若是灰色無法取消，保持原樣即可）
4. 安裝資料夾保持預設「C:\xampp」，請勿更改
   ⚠️ 裝到其他位置，治具系統會找不到資料庫
5. 解壓縮約需 5-10 分鐘（Windows 會逐一掃描檔案），請耐心等候
6. 裝完後 XAMPP Control Panel 會自動開啟：
   - 方式 A：直接關掉即可，安裝精靈會自動處理 MySQL
   - 方式 B：點 MySQL 那排的「Start」，出現綠色代表正常

================================================================
第 2 步（方式 A）：執行安裝精靈 JigToolingsSetup-1.3.1.exe
================================================================
1. 點兩下「JigToolingsSetup-1.3.1.exe」
   若出現藍色「Windows 已保護您的電腦」→ 按「其他資訊」→「仍要執行」
2. 依畫面按「下一步」，安裝資料夾預設 C:\JigSystem，也可以改成其他位置（例如 D:\JigSystem）
   ⚠️ 請勿選 C:\Program Files，系統需要在自己的資料夾寫入資料
3. 安裝精靈會自動：
   • 把 MySQL 設成開機自動啟動（以後不用手動開 XAMPP）
   • 建立資料庫
   • 建立桌面捷徑「治具管理系統」
4. 完成頁勾選「立即啟動治具管理系統」→ 完成

   若出現「尚未偵測到 XAMPP」→ 請先完成第 1 步
   若出現「MySQL 沒有啟動成功」→ 開啟 XAMPP Control Panel 按 MySQL
   的 Start，再執行安裝資料夾內的 scripts\install-database.bat

================================================================
第 2 步（方式 B）：解壓縮 zip 並建立資料庫
================================================================
1. 在 zip 檔上按右鍵 →「解壓縮全部」，放到固定位置（例如 D:\JigSystem）
2. 確認 XAMPP Control Panel 的 MySQL 是綠色
3. 點兩下資料夾內「scripts\install-database.bat」
   問密碼時直接按 Enter（XAMPP 預設沒有密碼）
   看到「Database installation completed!」就完成了（只需做一次）
4. 點兩下「START-JIG-NETWORK-APP.bat」啟動

   ⚠️ 方式 B 每次開機都要先開 XAMPP Control Panel 啟動 MySQL
      （或在 Control Panel 勾選 MySQL 左邊的「Service」設為開機自動啟動）

================================================================
第 3 步：啟動與登入
================================================================
1. 點兩下桌面「治具管理系統」（方式 B：START-JIG-NETWORK-APP.bat）
2. 黑色視窗會自動檢查 Java、MySQL、8080 port
3. 看到「[OK] The system is ready.」後，瀏覽器會自動開啟登入頁
4. 預設帳號 admin ／ 密碼 123456
   ⚠️ 登入後請立刻到「帳號設定」修改密碼！

   如果看到 [ERROR]：
   - MySQL is not responding → 開 XAMPP Control Panel，按 MySQL 的 Start
   - Port 8080 is already in use → 先執行 scripts\stop-system.bat 再重新啟動
     仍然被佔用（其他軟體在用 8080）→ 執行 scripts\change-port.bat 換一個 port，
     詳見 PORT-CHANGE-GUIDE-Windows.txt

================================================================
第 4 步：試用與正式授權
================================================================
• 第一次啟動自動開始 30 天免費試用，不需要授權檔
  剩餘天數可在系統的「授權（License）」頁面查看
• 購買正式授權：
  1. 在「授權」頁面複製 Machine ID
  2. 到 https://aurastudio.studio/license-center/ 登記
  3. 確認收款後，授權檔（.lic）會寄到您的信箱
  4. 在「授權」頁面選擇 .lic 檔 → Install License
• 授權綁定「伺服器電腦」，其他電腦用瀏覽器連線不需要另外授權

================================================================
【同公司其他電腦使用】
================================================================
1. 在伺服器執行 scripts\show-network-address.bat，查詢區域網路 IP
2. 其他電腦用瀏覽器開啟 http://（那個 IP）:8080
3. 連不上時，以「系統管理員身分」執行 scripts\open-firewall.bat
   （右鍵 → 以系統管理員身分執行）

================================================================
【每日備份】
================================================================
點兩下 scripts\backup-now.bat，備份檔存在 backups\ 資料夾
建議每天下班前執行一次。

================================================================
【版本更新】
================================================================
1. 系統首頁右上角「Check for Updates」→ 顯示目前版本與最新版本
2. 有新版本時，在伺服器點兩下 scripts\UPDATE-JIG-NETWORK-APP.bat
   → 自動備份資料、下載新版本、重新啟動
   ✅ 更新前會自動備份資料庫與檔案；治具記錄、授權、上傳檔案、
      以及您改過的 port 與資料庫設定全部保留
