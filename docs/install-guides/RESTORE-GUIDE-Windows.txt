【什麼時候需要還原？】
• 資料被誤刪、誤改，想回到某一天的狀態
• 電腦故障，重新安裝系統後要把資料找回來
⚠️ 還原會把「目前的資料庫」整個換成備份當時的內容，
   備份之後新增或修改的資料都會消失。還原前請先確認要選哪一份。

【備份放在哪裡？】
• 系統備份：安裝資料夾\backups\auto\（例如 C:\JigSystem\backups\auto\）
  檔名：jig-backup-日期_時間.zip，例如 jig-backup-2026-09-27_1800.zip
• 外接裝置備份：在「系統設定 → 資料備份」設定的外接資料夾
• 上傳的照片、圖檔：放在上述資料夾的 uploads-mirror 子資料夾

────────────────────────────────────────
方法一：用還原小工具（建議）
────────────────────────────────────────
1. 通知同事暫停使用系統（還原時系統會停止幾分鐘）
2. 打開安裝資料夾 → scripts，點兩下「restore-backup.bat」
3. 畫面列出最近的備份（最新的在最上面），輸入要還原的編號，按 Enter
   ※ 要用外接裝置上的備份：把那個 zip 檔「拖曳」到 restore-backup.bat 上放開
4. 確認畫面輸入大寫 YES 才會開始（輸入其他內容會取消，什麼都不改）
5. 小工具會自動：
   ① 先把「目前的資料庫」另存到 backups\before-restore-日期時間.sql
     （還原錯了也能退回）
   ② 停止系統
   ③ 還原資料庫
6. 看到「[OK] Restore completed」後，點兩下桌面「治具管理系統」重新啟動
7. 登入確認資料是否正確

────────────────────────────────────────
上傳的照片、圖檔怎麼辦？
────────────────────────────────────────
• 一般情況（只有資料庫要還原）：不用處理，照片還在原本的 uploads 資料夾。
• 電腦故障、uploads 資料夾不見了：
  把 backups\auto\uploads-mirror（或外接裝置的 uploads-mirror）裡的全部內容，
  複製到安裝資料夾的 uploads 資料夾。
  ※ uploads-mirror 是「目前最新」的檔案，不分日期。

────────────────────────────────────────
換到新電腦（或重新安裝）後還原
────────────────────────────────────────
1. 在新電腦照安裝說明安裝 XAMPP 與治具系統
2. 把舊的備份 zip 複製到新電腦任何位置
3. 把 zip 拖曳到新安裝的 scripts\restore-backup.bat 上
4. 依畫面輸入 YES 完成還原
5. 把舊的 uploads-mirror 內容複製到新安裝的 uploads 資料夾
6. 授權檔需要重新申請（授權綁定電腦）：
   到 https://aurastudio.studio/license-center/ 登記新電腦的 Machine ID

────────────────────────────────────────

────────────────────────────────────────
常見問題
────────────────────────────────────────
Q：畫面顯示「No backups found」？
A：backups\auto 裡沒有備份。請確認自動備份有開啟，或把外接裝置上的 zip 拖曳到小工具上。

Q：顯示「MySQL is not responding」？
A：開啟 XAMPP Control Panel，按 MySQL 的 Start，再執行一次。

[WHEN DO I NEED TO RESTORE?]
- Data was deleted or changed by mistake and you want a previous day back
- The computer failed and you reinstalled the system
!! Restoring replaces the WHOLE current database with the backup. Anything
   added or changed after that backup is lost. Choose the backup carefully.

[WHERE ARE THE BACKUPS?]
- System backups: <install folder>\backups\auto\ (e.g. C:\JigSystem\backups\auto\)
  File name: jig-backup-DATE_TIME.zip, e.g. jig-backup-2026-09-27_1800.zip
- External drive backups: the folder set in System Settings -> Data Backup
- Uploaded photos and drawings: the uploads-mirror folder inside the above

----------------------------------------
Method 1: Restore tool (recommended)
----------------------------------------
1. Ask colleagues to stop using the system (it stops for a few minutes)
2. Open the installation folder -> scripts, double-click "restore-backup.bat"
3. Recent backups are listed (newest first). Type the number and press Enter
   * To use a backup from an external drive: drag that zip file onto
     restore-backup.bat and drop it
4. Type YES in capitals to start (anything else cancels; nothing changes)
5. The tool automatically:
   (1) saves the CURRENT database to backups\before-restore-DATE-TIME.sql
       (so a wrong restore can be undone)
   (2) stops the system
   (3) restores the database
6. After "[OK] Restore completed", double-click the desktop shortcut to start
7. Sign in and check the data

----------------------------------------
What about uploaded photos and drawings?
----------------------------------------
- Usual case (only the database is restored): nothing to do; the files are
  still in the uploads folder.
- Computer failure, uploads folder lost: copy everything from
  backups\auto\uploads-mirror (or uploads-mirror on the external drive)
  into the installation's uploads folder.
  * uploads-mirror holds the latest files, not per-date copies.

----------------------------------------
Restoring on a new computer (or after reinstalling)
----------------------------------------
1. Install XAMPP and the system on the new computer (see the install guide)
2. Copy the backup zip to the new computer
3. Drag the zip onto scripts\restore-backup.bat of the new installation
4. Type YES to restore
5. Copy the old uploads-mirror contents into the new uploads folder
6. The license is bound to the computer, so request a new one with the new
   Machine ID: contact gossipred5598@gmail.com

----------------------------------------
Undo a restore
----------------------------------------
The data from before the restore is in backups\before-restore-DATE-TIME.sql.
Contact us and we will help: gossipred5598@gmail.com

----------------------------------------
FAQ
----------------------------------------
Q: "No backups found"?
A: backups\auto is empty. Check that automatic backup is on, or drag a zip
   from the external drive onto the tool.

Q: "MySQL is not responding"?
A: Open XAMPP Control Panel, click Start on MySQL, then run the tool again.
