# Jig Toolings Network Distribution

This repository manages distribution, packaging, release metadata, and update planning for the network/server version of Jig & Toolings Management System.

Core application source code lives in:

```text
https://github.com/gossipred/jig-and-toolings-management-system
```

This repository is for:

- Windows network app packages
- macOS network app packages
- release notes
- update manifests
- customer data protection policy
- future updater and installer workflows

It does not store customer data, private license files, generated runtime folders, XAMPP installers, or release zip binaries in Git.
