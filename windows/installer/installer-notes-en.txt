================================================================
  Jig & Toolings Management System
  Windows Network Edition - Setup notes
================================================================

[INSTALLATION HAS TWO STEPS: XAMPP FIRST, THEN THIS SYSTEM]

[ALREADY USING AN OLDER VERSION?]
Just run this wizard and keep the existing folder to upgrade.
License, uploaded files, database, port and settings are kept, and a
backup is made first in the backups folder. (No need to reinstall XAMPP.)

----------------------------------------
Step 1: Install XAMPP (MySQL database, once)
----------------------------------------
1. Run XAMPP-installer.exe (on the same download page as this setup)
2. If a "UAC / Program Files" warning appears, click OK
   (you do NOT need to turn off UAC)
3. "Select Components": only MySQL is needed. You may untick Tomcat,
   Perl, FileZilla, Mercury, Webalizer and Fake Sendmail
   (leave Apache/PHP as they are if they are greyed out)
4. Keep the default folder "C:\xampp" - do not change it
5. Unpacking takes about 5-10 minutes - please wait
6. XAMPP Control Panel opens at the end; you can close it

----------------------------------------
Step 2: Run this setup wizard
----------------------------------------
The wizard automatically:
  - sets MySQL to start with Windows
  - creates the database and its own database account (jig_app)
  - creates a desktop shortcut starting with "Jig Toolings"

----------------------------------------
Step 3: Start and sign in
----------------------------------------
1. Double-click the desktop shortcut
2. After "[OK] The system is ready." the login page opens
3. Sign in with admin / 123456 - you will be asked to set a new
   password (at least 8 characters)
4. To purchase a license, copy the Machine ID from the "License" page
   and register at https://aurastudio.studio/license-center/

Other computers in the company: open http://(server IP):8080
(scripts\show-network-address.bat shows the IP)
If another program uses port 8080: run scripts\change-port.bat,
see PORT-CHANGE-GUIDE-Windows.txt
