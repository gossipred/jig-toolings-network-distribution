================================================================
  治具及模具管理系統（Jig & Toolings Management System）
  Windows 網路版安裝說明（安裝精靈）
================================================================

【安裝分兩步：先裝 XAMPP，再裝治具系統】

────────────────────────────────────────
第 1 步：安裝 XAMPP（MySQL 資料庫，只需裝一次）
────────────────────────────────────────
1. 執行 XAMPP-installer.exe（跟本安裝檔放在同一個下載頁）
2. 若跳出「UAC / Program Files」警告視窗，按「確定」即可，
   不需要關閉 UAC
3. 「Select Components」頁：只需要 MySQL。
   Tomcat、Perl、FileZilla、Mercury、Webalizer、Fake Sendmail
   都可以取消勾選，安裝會快很多
   （Apache、PHP 若是灰色無法取消，保持原樣即可）
4. 安裝資料夾保持預設「C:\xampp」，請勿更改
5. 解壓縮約需 5-10 分鐘（Windows 會逐一掃描檔案），請耐心等候
6. 裝完後 XAMPP Control Panel 會問語言、會自動開啟，可以直接關掉

────────────────────────────────────────
第 2 步：執行本安裝精靈（就是你現在看到的這個）
────────────────────────────────────────
安裝精靈會自動：
  • 把 MySQL 設成 Windows 服務（開機自動啟動，不用每次手動按 Start）
  • 建立資料庫
  • 建立桌面捷徑「治具管理系統」

────────────────────────────────────────
第 3 步：啟動與登入
────────────────────────────────────────
1. 點兩下桌面「治具管理系統」
2. 看到「[OK] The system is ready.」後，瀏覽器會自動開啟登入頁
3. 預設帳號 admin ／ 密碼 123456，登入後請立刻修改密碼
4. 出現 License Required 畫面時，複製 Machine ID 到
   https://aurastudio.studio/license-center/ 登記授權

同公司其他電腦：用瀏覽器開 http://（伺服器 IP）:8080
（IP 可執行安裝資料夾內 scripts\show-network-address.bat 查詢）
